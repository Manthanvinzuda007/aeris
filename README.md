# AERIS — AI-Enabled Real-time Intelligence for Storms

**Short-term (0–180 min) thunderstorm and lightning nowcasting system for India**

AERIS is a live map-based nowcasting dashboard: pick a storm scenario, watch synthetic radar/satellite/lightning data evolve in real time, scrub a 0–180 min time strip, and see thunderstorm and lightning risk heatmaps update with a genuinely-computed model.

---

## Quick Start

```bash
# Clone and install
git clone <repo-url>
cd aeris
npm install

# Run locally
npm run dev
# Open http://localhost:3000
```

**Zero external API keys or data agreements required.** Everything runs on synthetic data.

## What's Real vs. What's Simulated

> **AERIS's architecture, data flow, and model design are based on real operational systems:** the IMD Doppler radar network, INSAT-3D/3DR satellites, WWLLN/GLM/LIS lightning networks, GFS/ECMWF/WRF NWP fields, ConvLSTM/diffusion-based nowcasting research, and multi-hazard fusion systems like MeteoSwiss's COALITION-4.
>
> **For this prototype, all data is synthetic** — generated by seeded simulators standing in for each real source — so AERIS can be demonstrated without live data access.

### Model

AERIS uses a **rule-based motion-vector extrapolation** nowcast (TITAN/ROVER-style heuristic). This is a real, widely-used technique in operational meteorology:

1. **Motion estimation:** Block-matching between consecutive radar frames to estimate storm cell motion vectors.
2. **Semi-Lagrangian advection:** Extrapolates the current radar field forward along motion vectors.
3. **Atmospheric modulation:** Combines extrapolated reflectivity with CAPE, shear, and humidity to produce calibrated thunderstorm and lightning probability maps.
4. **Lead-time decay:** Predictions naturally lose confidence at longer lead times, reflected in decreasing intensities.

The model genuinely computes predictions from the synthetic time series — it is **not** a canned animation or static image. However, it is a heuristic, not a trained neural network. The same input/output interface would accept a trained ConvLSTM or U-Net with no code changes elsewhere.

### Data Sources (Synthetic → Real Swap Points)

| Synthetic Module | Real-World Source It Replaces | Swap Point |
|---|---|---|
| `generateRadarGrid()` | IMD Doppler Weather Radar network (32 S/C/X-band radars) | Replace with IMD API or MOSDAC data feed |
| `generateSatelliteChannels()` | INSAT-3D/3DR IR & WV channels, GOES, Himawari | Replace with MOSDAC/EUMETSAT data access |
| `generateLightningFlashes()` | INSAT LIS, WWLLN, GOES-GLM, OpenWeatherMap Lightning API | Replace with WWLLN or commercial lightning API (DTN, XWeather) |
| `generateAtmosphericFields()` | GFS/ECMWF analysis + WRF mesoscale model | Replace with GFS GRIB2 download or ECMWF API |
| `predictThunderstormRisk()` | Trained ConvLSTM/U-Net on real radar sequences | Replace rule-based model with trained weights |

### Performance

> ⚠️ **All performance metrics are measured on synthetic data** and should not be interpreted as real-world verified skill scores.

The synthetic data generators produce physically-plausible storm evolution (growth → maturity → decay with momentum-based drift), and the model produces sensible extrapolations within this synthetic environment.

## Scenarios

AERIS ships with three pre-seeded demo scenarios:

1. **Afternoon Thunderstorm** — Classic Indian afternoon convective buildup. A single large cell forms near central India, grows over 60 minutes, peaks at 90 minutes, and decays by 150 minutes.
2. **Squall Line** — Linear convective system with multiple cells aligned NE-SW, moving eastward across a 500km band.
3. **Isolated Cell** — Small, intense supercell-like storm near Kolkata with a rapid growth/decay cycle.

Each scenario uses a fixed seed for reproducible demonstrations.
